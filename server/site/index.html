sidemdm

Enroll an Android phone from this computer, then hand it back unmanaged.

Release details: release.json

  1. Back up, then factory-reset the phone. Enrollment only starts from the first-run welcome screen.
  2. On the welcome screen, tap six times to open the QR scanner.
  3. Join the same Wi-Fi as this computer if asked, then scan this code.
  4. Accept the work-profile setup. A Work tab appears in your app drawer.
  5. Open the Work Profile app there and tap Remove Work Profile (two confirmations). You end up with a clean, unmanaged phone that keeps its personal side.

If you see "App blocked to protect your device," this method won't work on that phone and there's no bypass. Served over plain HTTP on your LAN — the QR pins the APK by SHA-256, so a swapped file is rejected.

The server is only needed for the download; removal works with no network at all. Show this page on another device's screen, keep the brightness up and avoid glare.
